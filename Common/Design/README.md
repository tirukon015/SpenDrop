# Design

`tokens.json` captures SpenDrop's visual identity from the iOS app: Apple system colours (light/dark), grouped
backgrounds with white/charcoal cards (radius 16, inner panels 14, tiles 12), uppercase bold section headers,
rounded bold money figures, the SpenDrop accent blue (#0D73D9 / #3399F2), and the five sections Home · Transactions ·
PayBook · Breakdown · More.

Web specifics: text-coloured tints are deepened (light) / lightened (dark) to meet WCAG AA contrast; vivid tints stay
for icons, bars and badges. Navigation: bottom tab bar on phones, icon rail on tablets, sidebar on desktop.
